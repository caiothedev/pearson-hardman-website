# PEARSON HARDMAN WEBSITE - ᴘᴛ

Site corporativo fictício da Pearson Hardman, a firma de advocacia de Manhattan da série *Suits*. Projeto de fã e de portfólio, sem fins comerciais e sem vínculo com a USA Network, a NBCUniversal ou a Universal Content Productions.

## Como rodar

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.
